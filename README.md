# 3D Printing Files

3D-printable models from DM Machine Tool LLC.

## Endmill trays

One tray per flute count, each in its own folder (`2_Flute` … `6_Flute`):

| File | Use |
|---|---|
| `*_Single_Color.stl` | Whole tray, one color |
| `*_Body.stl` + `*_Label_Color2.stl` | Tray body and label as separate parts for two-color printing |
| `*_Two_Color.3mf` | Two-color project, ready to slice |
